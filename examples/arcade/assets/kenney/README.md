Kenney Arcade Assets
====================

This folder contains compact, derived gameplay strips and small sheet previews built from the Kenney packs in `~/Downloads`.

Layout:

- `strips/`: 8-frame, 48px-tall strips for Glyph's simple sprite-frame renderer.
- `sheets/`: resized spritesheet/tilemap previews used as set dressing in the microgames.

The bundle intentionally does not copy the raw Kenney folders. The generated assets are lightweight enough to keep in the example arcade while still showcasing each pack.
